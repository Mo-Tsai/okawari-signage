# 按鈕機｜怎麼測、怎麼燒、怎麼出貨

> 這個資料夾就是「續碗按鈕機」的全部。四個檔案各司其職：
>
> | 檔案 | 跑在哪 | 做什麼 |
> |---|---|---|
> | `hdlink.py` | 兩邊都跑 | 跟卡講話的協議＋按鈕邏輯（擲骰、冷卻、切回原節目） |
> | `main.py` | M5Stack | 螢幕、三顆鍵、Wi-Fi，包著 hdlink 跑 |
> | `做設定檔.py` | 筆電 | 從後台的 stores.json 產生 button_config.json |
> | `桌上測試.py` | 筆電 | 沒有 M5Stack 也能先測整條路（鍵盤代替按鍵） |

---

## 一、假日先做：不用等 M5Stack 的實測（★ 這是本週末的重點）

機器還沒到，但整條路可以先用筆電走一遍。2026-08-20 已經用「假卡」
驗證過程式邏輯全通，剩下的就是換成真卡：

1. 測試卡接電
2. 筆電連卡的 Wi-Fi 熱點：`C16L-D24-000A2`（密碼 88888888）
3. 開命令列，cd 到這個資料夾：
   ```
   python 做設定檔.py
   python 桌上測試.py
   ```
4. 按 **Enter** → 屏應該在一秒內跳劈石動畫（中獎或沒中），
   播完 8 秒自動切回原本的時段畫面
5. 動畫播放中狂按 Enter → 應該全部被擋掉（顯示「播放中」）

### 這一輪要順便量的三個數字（寫下來）

- [ ] **按下到屏有反應，幾秒？**（SwitchProgram 延遲——系統架構 §8 那個老問題）
- [ ] **播完切回原節目，順不順？** 會不會黑一下？
- [ ] **卡熱點的穩定度**：連著半小時會不會自己斷？

### 4G 分享器（HUB）模擬門店：第二輪測

分享器插 SIM 卡開機 → **卡改用網路線接分享器** → 筆電連分享器的 Wi-Fi：

```
python 做設定檔.py test --router 分享器WiFi名 分享器密碼 卡拿到的IP
python 桌上測試.py
```

（卡的 IP 去分享器管理頁的「已連線裝置」裡看。）
這一輪成功 = 8/31 現場的網路拓樸已經預演過了。
**注意：按鈕這條路完全不需要 SIM 卡有網路**——分享器只是當店內區網用，
SIM 是給以後遠端維運備案用的，沒訊號也不影響按鈕。

## 二、M5Stack 到貨：燒錄（第一次我們一起做）

1. **燒底層韌體**：電腦裝 [M5Burner](https://docs.m5stack.com/en/download)，
   USB-C 接上 M5Stack → 選 **CORE → UIFlow2** → Burn
2. **傳我們的程式**：電腦裝一次 `pip install mpremote`，然後在這個資料夾：
   ```
   mpremote connect auto fs cp hdlink.py :flash/hdlink.py
   mpremote connect auto fs cp main.py :flash/main.py
   mpremote connect auto fs cp button_config.json :flash/button_config.json
   mpremote connect auto reset
   ```
3. 重開後螢幕變**綠色 READY** 就完成了。按中鍵 → 門頭屏跳動畫

（若 UIFlow2 的螢幕/按鍵 API 跟 main.py 有出入——不同版本會有——
只改 main.py 的畫面段，跟卡講話的部分不動。到時候丟給 Claude 調。）

### 螢幕顏色 = 狀態燈

| 顏色 | 意思 | 店員要做什麼 |
|---|---|---|
| 🟢 綠 READY | 可以按 | 中鍵=續碗，右鍵=滿千送百 |
| 🟠 橘 + 倒數 | 動畫播放中 | 等倒數完，連按沒用 |
| 🔵 藍 WAIT | 開機連線中 | 等幾秒 |
| 🔴 紅 ERROR | 連不到卡 | 按左鍵；還是紅→拔電再插；還是紅→打給 Mo |

## 三、日常維護的兩條規則

1. **每次在後台重新「發佈到卡」之後**，節目 guid 會換，按鈕機會失效。
   重跑 `python 做設定檔.py` → 重傳 `button_config.json`（上面第 2 步最後兩行）。
   忘了做的症狀：按了顯示「卡拒絕了」。
2. **combo1~3 或滿千送百（man1000）發佈之後**，做設定檔.py 會自動偵測：
   - 有 combo1~3 → 中鍵自動變成連按升級模式（COMBO 1→2→3）
   - 有 man1000 → 右鍵自動掛上滿千送百
   不用改任何程式。

## 四、開新店（出貨流程）

1. `python 做設定檔.py 新店代號`（門店用分享器就加 `--router ...`）
2. `mpremote` 把三個檔案傳進新的 M5Stack（同上面第 2 步）
3. 現場測一次三顆鍵 → 貼標籤「請勿拔除 · 續碗按鈕」→ 交機
4. 這台機器從此只認這家店的卡。改嫁 = 重跑 1–2，兩分鐘

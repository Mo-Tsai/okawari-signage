## 開起來

連點兩下 **`啟動.bat`**。

問你控制卡 IP 的時候：**知道就打，不知道直接按 Enter，程式會掃描整個網段找卡。**
Port 直接按 Enter 用預設的 10001。

所有結果自動存到 `../03_現場存檔/現場紀錄_日期_時間.txt`，含卡回的原始 XML。

## 選單

| 選項 | 做什麼 |
|---|---|
| **1　一鍵全查** | 接上卡先按這個。型號、韌體、**屏幕像素尺寸**、網路現況、有沒有 Wi-Fi、主動回連設定、多屏同步、亮度、定時開關屏 |
| **2　切節目延遲實測** | 送出切換 → 你盯著屏 → 畫面一變按 Enter。會記「卡回應」和「眼睛看到」兩個時間 |
| **3　設亮度** | 1〜100。室內百貨建議 40〜60。按下去立刻看得到結果 |
| 4　抓螢幕截圖 | 叫卡把現在的畫面傳回來存檔 |
| **5　重開控制卡** | 要打 `yes` 才執行。重開後盯著看會不會自己接著播 |
| 6　只讀設備資訊 | 選項 1 的縮小版 |
| 7　進階：送任意指令 | 廠商報給你某個指令名稱時用。格式：`<in method="GetWifiInfo"/>` |
| 9　重新連線 | 連線斷了、換卡、或重新掃描 |
| 0　結束 | |

## 出事的時候

**掃不到卡** — 卡可能在別的網段（常見出廠值 `192.168.0.x`）。程式會問你要不要指定網段再掃一次。

**連不上** — 多半是筆電 IP 跟卡不同網段。卡是 `192.168.1.100`，筆電就設 `192.168.1.50`。

**卡回報錯誤** — 程式會翻成中文，例如 `錯誤 21（無效的 xml 索引值）` 就是節目 index 給錯。
`錯誤 43（不支援的方法）` 是這張卡的韌體不認得該指令，**記下是哪個指令帶回來**。

**切節目一直失敗** — 先看選項 1 裡的多屏同步是不是開的，SDK 文件明講切節目前要關掉。

**程式完全跑不起來** — 用 `官方測試工具/SDKTest.exe`，灰度原廠圖形介面工具，不用裝 Python。

## 這個程式是怎麼來的

把 `門頭程式/灰度SDK_V3.1/` 的 `HDSDK.zip` 解開，讀 `Protocol/HDSDK.cpp` 跟
`SDK/SDKInfo.h` 的 C++ 原始碼，照協議重寫成 Python。

實作：TCP 封包框架（`長度 u16 + 指令 u16 + 內容`，little-endian）、版本協商
`0x2001→0x2002`、guid 握手、心跳自動回應、XML 超過 9200 bytes 自動分段收送、
53 個錯誤碼中文化、掃描網段找卡（逐一試連 10001 再真的握手驗證）。

只用 Python 標準函式庫，不需安裝套件，不需網路。

出門前用模擬控制卡跑過 20 項協議測試全通過，但**真卡沒測過**。
行為若不同，紀錄檔會存下卡回的原始 XML。

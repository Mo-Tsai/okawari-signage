後台位置

這個頁面本身只是介面，真正跟控制卡講話的是「後台」。 下面填後台在哪裡。換場地、換網路就改這一格，其他都不用動。

連不上的時候先看這裡：

· 這個頁面走 https、後台走 http 的話，瀏覽器只准連 localhost， 區網 IP（192.168.x.x）會被擋掉。要嘛把頁面存到本機用 http 開， 要嘛給後台一個 https 網址（見 遠端架構.md 的 Cloudflare Tunnel 那節）。

· 後台沒開 → 先在那台電腦跑 後台.bat。

離線預覽模式。現在看到的是排版和畫面預覽，沒有連到任何後台， 按鈕不會真的對控制卡做事。要實際操作請按右上角「連線設定」填後台網址。

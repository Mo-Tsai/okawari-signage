後台位置

這個頁面只是遙控器，真正跟控制卡講話的是「後台」。下面填後台在哪裡； 換場地、換網路就改這一格，其他都不用動。

連不上的時候先看這裡：

· 手機、平板不要開 GitHub 網址 —— https 的頁面只准連 localhost， 連不了 192.168.x.x。手機請直接開 http://筆電的IP:8080，畫面一模一樣。

· 後台沒開 → 先在那台看得到卡的電腦上跑 後台.bat。

OKAWARI 門頭屏

模擬後台

沒有卡、沒有按鈕，先把整套跑一遍。 把 屏 開在另一個視窗， 在這裡按，那邊就會動。

觸發

續飯按第 0 次。30 秒沒人按就歸零。

切換延遲

這一格是這個模擬器最重要的東西。 拉到 300 跟拉到 2000，按下去的感覺完全不一樣。 實際數字要用 _測_SwitchProgram延遲.py 上機量。 量出來超過 1500 ms 的話，三段累積式的 COMBO 就不要做， 改成按一次播完整的三連震。

時間

不用等到晚上七點才看得到晚間那段。

門店與主角

兩店畫布差 8%，屏的長寬比會跟著變。

紀錄

這個模擬器不能代替什麼

兩頁是靠瀏覽器的 BroadcastChannel 講話，只在同一台機器、同一個瀏覽器有效。 拿 iPad 開這一頁去按，另一台電腦的屏是不會動的 —— 那要走真的後台伺服器。

真機的路徑是：按鈕 → 店內小主機 → SwitchProgram → 控制卡 → 屏。 這裡模擬的是那條路徑看起來的樣子，不是那條路徑本身。 上機之後每一段的實際延遲還是要量。
